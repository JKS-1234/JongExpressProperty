# JongExpressProperty
## Chinese (zh-Hans) pages

Static `/zh/` pages are generated by `build.py` via `translate_zh.py` (DeepL, build time).

- `DEEPL_API_KEY` (env / GitHub secret) enables translation; without it the build uses `i18n/zh-cache.json` + `i18n/zh-overrides.json` and skips untranslated pages.
- `DEEPL_API_PLAN` = `free`/`pro` (or key ending `:fx` = free), or `DEEPL_API_URL` to override the endpoint.
- `DEEPL_CHAR_BUDGET` caps cumulative characters (default 900000, one-time 1M credit); usage is tracked in `i18n/usage.json`.
- `i18n/glossary.json` lists do-not-translate terms; `i18n/zh-overrides.json` (source text -> Chinese) always wins.
- Validate: `python tests/validate_site.py`.
